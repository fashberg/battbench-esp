Charger

The charger accepts only one Bluetooth connection: to use the SkyRC app or BattBench's own Bluetooth, pause Bluetooth here or switch it off. By itself the ESP sends only status queries; commands that start or stop a task come from BattBench (charge profiles) and only after a confirmation there.

Storage

RAM keeps every reading but loses them on a power loss. The flash log keeps one reading per slot every n seconds (see below; a change of state at once), writes each one right away and keeps them over a power loss. Fetching deletes nothing: both are ring buffers that drop their oldest readings when full, so BattBench should fetch before the range runs out. Before a restart (settings, update, button) the readings still held back are written to flash; a power loss loses at most the last n seconds per slot that BattBench has not fetched yet.
